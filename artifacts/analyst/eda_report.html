Methodology

The raw file is parsed with its verified delimiter and encoding, then validated column-by-column against a machine-readable dataset contract (types, ranges, category domains, session integrity). Cleaning is non-destructive: nothing is imputed, dropped, coerced, or clipped — invalid data would stop the run. A composite session_key is derived and rows are sorted into canonical click order. All descriptive numbers below are computed by deterministic Python and written to artifacts/analyst/eda/eda_metrics.json before any prose is written, so every figure here is traceable to a computed source.

Figures

Findings

  • Category-sticky browsing. The next click stays in the same category 81.2% of the time — a highly learnable target where the value is in the switch cases.
  • Balanced category mix. trousers leads at 30.1%; the sale bucket is 23.4%.
  • Strongest cross-category move: skirts → blouses at 9.3% (descriptive, not causal).
  • Short, long-tailed sessions. median 4.0 clicks; 21.0% are single-click.
  • One dominant market. Poland is 81.0% of clicks.

Limitations

  • 2008 data from a single shop — not current-market truth.
  • Description, not causation — EDA cannot explain why shoppers switch categories.
  • One dominant country — minor-market patterns rest on few sessions.
  • Coded categorical fields — labels are display-only and carry no ordering.
  • Clicks only — no purchases, baskets, or revenue.
